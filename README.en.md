# CBZ to PDF converter

[🇧🇷 Português](README.md)

This project was initially created as a response to a supposed lack of alternatives for CBZ to PDF conversions, focused on comics and Kindle reading.

However, I discovered an open-source software called [KCC](https://github.com/ciromattia/kcc) that already performs this function effectively, while also offering other formats and features. I decided to finish a basic feature so the effort wouldn't go to waste, but the software I personally recommend is linked above.

In the future, I will turn this project into a web version, aiming to reach audiences that KCC doesn't reach (like me, until I started this project) and other people who prefer to handle their needs without local downloads.
